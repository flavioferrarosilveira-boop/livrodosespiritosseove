Digite palavras do título, nome do espírito, série ou tema. Quando os textos estiverem indexados, a busca encontra trechos e citações dentro dos livros.

Busca no texto completo — para ativar, rode o script abaixo na sua máquina e copie a pasta data/textos/ para o projeto: 

pip install requests beautifulsoup4
python3 tools/baixar_obras.py
